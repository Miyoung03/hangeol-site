한결 · 심플 모노라인 업데이트 (2026-10-12)
========================================
- 봉사 · 운동 · 독서 · 공부 등 항목 아이콘을 검정/회색 선 아이콘으로 통일했습니다.
- 상단 슬라이드, 항목 선택 버튼, 통계, 기록 목록, 설정 화면에 동일한 스타일을 적용했습니다.
- 항목 설정에서 아이콘 모양과 회색 농도를 변경할 수 있습니다.
- 기존 시간 기록, 항목별 목표, 타이머, 좌우 스와이프, 백업/복원 기능은 유지합니다.
- 기존 데이터를 삭제하거나 초기화하지 않습니다. 업데이트 전에 전체 백업을 권장합니다.

GitHub 업로드: ZIP 압축을 풀고 index.html, sw.js, manifest.webmanifest,
icon-180.png, icon-192.png, icon-512.png 파일을 기존 저장소의 같은 이름으로 교체하세요.
.nojekyll 파일이 있다면 그대로 유지하세요.

한결 — 아이폰 시간 기록 앱
========================

1. 컴퓨터에서 먼저 써 보기
  - index.html을 더블클릭하세요.
  - 인터넷 주소(file://)로 열면 홈 화면에 설치/오프라인 캐싱은 사용할 수 없지만 기록 기능은 테스트할 수 있습니다.

2. 아이폰 홈 화면에 설치하기 (무료 웹앱)
  ① https://github.com 에 로그인합니다.
  ② 새 공개 저장소를 만들거나, 기존에 사용하던 앱 저장소를 엽니다.
  ③ 이 폴더의 다음 파일들을 저장소 최상위에 올립니다.
     index.html / manifest.webmanifest / sw.js / icon-180.png / icon-192.png / icon-512.png
     (설명서 파일은 올리지 않아도 됩니다.)
  ④ Settings → Pages → Source 'Deploy from a branch' → Branch 'main' / '(root)' → Save.
  ⑤ Pages에 표시된 Visit site 주소를 아이폰 Safari에서 엽니다.
  ⑥ Safari의 공유 버튼 → '홈 화면에 추가' → '웹 앱으로 열기' 옵션이 보이면 선택 → 추가합니다.

3. 앱 사용법
  - 홈 상단의 이번 달 누적시간 카드는 항목별로 한 장씩 표시됩니다. 봉사 → 운동 → 독서 → 기타 순으로 좌우 스와이프하거나 양쪽 화살표로 전환합니다.
  - 홈에서 기록할 항목을 먼저 선택합니다.
  - 시작 → 종료: 선택한 항목으로 실제 경과 시간을 1분 단위로 반올림해 저장합니다.
  - 직접 입력: 드롭다운 대신 원하는 항목 버튼을 누르고 날짜, 시간/분, 메모를 입력해 저장합니다.
  - 최근 기록/날짜별 기록: 항목마다 심플한 선 아이콘과 무채색 구분 표시가 적용됩니다.
  - 홈 상단 슬라이드: 항목마다 누적시간, 월 목표, 달성률과 남은 시간이 각각 표시됩니다.
  - 각 슬라이드의 [목표 설정] 또는 [목표 변경]을 누르면 그 항목의 월 목표를 바로 설정합니다.
  - 각 항목의 목표는 서로 독립적이며, 매달 반복 적용됩니다. 목표를 변경해도 기존 시간 기록은 유지됩니다.
  - 항목별 기록시간은 선택한 달 기준으로 각각 집계됩니다. 전체 연간 누적시간은 통계에서 볼 수 있습니다.
  - 통계: 9월 1일~다음 해 8월 31일 연간 합계/월별 시간/항목별 합계 확인.
  - 기록: 현재 선택한 달의 날짜별 기록을 수정/삭제.
  - 예전 버전에서 설정한 통합 목표값은 호환성을 위해 백업에 유지하지만 화면에서는 항목별 목표만 설정합니다.
  - 설정 → 항목별 목표 설정: 항목 추가, 항목별 목표 수정, 이름/모노라인 아이콘/회색 농도 변경.
  - 통계 → 항목별 기록 합계: 선택한 달 또는 9월~8월 기간 동안 항목마다 따로 합산합니다.
  - 설정 → 전체 백업: 모든 기록을 JSON 파일로 저장하고, 복원할 수 있습니다.

4. 데이터 보관 주의
  - 데이터는 현재 브라우저/홈 화면 앱의 로컬 저장소에 보관됩니다.
  - 서버나 GitHub 저장소에는 입력한 기록이 올라가지 않습니다.
  - Safari 탭에서 입력한 내용이 홈 화면 앱에 자동으로 옮겨지지 않을 수 있습니다.
    설치한 후에는 홈 화면 아이콘에서 앱을 열어 기록하는 것을 권장합니다.
  - Safari 데이터 삭제, 아이폰 변경, 앱 삭제 전에는 '전체 백업'을 사용하세요.
  - 서버 로그인/아이클라우드 자동 동기화는 지원하지 않습니다.
  - 온라인 게시 뒤 최초 정상 실행하면 오프라인 재접속을 지원할 수 있지만 기기/설정에 따라 제한될 수 있습니다.

5. 기존 '나의 50시간' 앱에서 옮기기
  - 같은 브라우저 저장소에서 열리는 경우 v1/v2 기록을 찾아 자동 변환을 시도합니다.
  - 다른 주소/홈 화면 앱으로 옮긴다면 기존 앱의 '전체 백업'에서 JSON을 내려받아,
    한결의 '설정 → 백업 복원'으로 가져오세요.
  - 기존 기록을 변환하기 전에 JSON 백업을 별도로 보관하는 것이 안전합니다.
  - 새 설치의 첫 항목은 봉사이며, 두 번째는 운동입니다. 이미 쓰던 앱의 항목과 기록은 기존 이름을 유지합니다. 예전 공부 항목을 봉사로 바꾸려면 설정 → 해당 항목 [수정]을 누르세요.

* 이 버전은 무료로 설치 가능한 웹앱(PWA)이며, 앱스토어 등록용 네이티브 iOS 앱(.ipa)이 아닙니다.

6. GitHub에 기존 앱 업데이트
  - 먼저 한결 앱의 설정 → 전체 백업으로 JSON 파일을 안전하게 보관하세요.
  - ZIP 압축을 풀고 index.html, sw.js, manifest.webmanifest, 아이콘 PNG 3개를 기존 GitHub 저장소의 맨 위에 업로드해 같은 이름의 파일을 교체합니다.
  - Commit changes를 완료하고 Pages 배포가 끝나면 Safari에서 기존 앱 주소를 다시 엽니다.
  - 설치형 앱에 이전 화면이 남으면 앱을 완전히 닫았다가 다시 여세요. 기록을 보관해야 하므로 앱 삭제나 Safari 데이터 삭제는 피하세요.
