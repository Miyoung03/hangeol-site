한결 맞춤 항목 R4 업데이트 (2026-10-13)
=======================================
1) 기존 앱에서 [설정 → 전체 백업]으로 기록을 먼저 저장하세요.
2) 이 ZIP을 압축 해제한 뒤 GitHub 저장소 최상위에 index.html, sw.js, manifest.webmanifest, icon-180.png, icon-192.png, icon-512.png, 버전확인.txt 파일을 올려 기존 파일을 교체하세요.
   (.nojekyll도 그대로 두면 됩니다.)
3) Commit changes 누르고 Pages 배포가 끝나면 Safari에서 기존 앱 주소 뒤에 ?v=icon-r4를 붙여 열어 보세요.
4) 설정 → + 항목 추가 → 아이콘 선택 → 목표 설정 → 저장을 누르면 홈의 시간 기록하기에 해당 항목만 표시됩니다.
5) 항목 이름은 선택한 아이콘의 의미(봉사/운동/독서 등)에 따라 자동으로 붙습니다. 별도의 이름 입력은 없습니다.
6) 기존 기록·목표가 있는 항목은 보존됩니다. 과거 버전에서 자동 생성된 기록 없는 기본 항목은 첫 업데이트 시 정리됩니다.

주의: 이 앱은 기록을 현재 기기의 브라우저 저장소에 보관합니다. 앱을 삭제하거나 Safari 저장 기록을 지우지 마세요.
ZIP 파일 자체는 GitHub에 올리지 말고 압축을 푼 파일을 올려야 합니다.
