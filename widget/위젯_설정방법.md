# 한바퀴 아이폰 위젯 설정 방법

아이폰 홈 화면 웹앱은 혼자서 위젯을 만들 수 없어요. 그래서 아래 두 가지를 이어서 위젯을 만들어요.

```
한바퀴 앱 ──(이번 달 합계 전송)──▶ Cloudflare Worker ◀──(읽어 가기)── Scriptable 위젯
```

- **Cloudflare Worker:** 무료로 쓸 수 있는 작은 서버예요. 앱이 보낸 합계를 잠깐 보관해요.
- **Scriptable:** App Store의 무료 앱이에요. 그 합계를 읽어 위젯으로 그려 줘요.
- **보내는 내용:** 항목 이름, 색, 이번 달·지난달 합계, 목표, 오늘 목표와 오늘 한 시간만 보내요. 개별 기록, 메모, 만난 사람, 사진은 보내지 않아요.

준비물: 이메일 주소(Cloudflare 가입용), 아이폰.
처음 한 번만 20분쯤 걸려요.

---

## 1단계 · Cloudflare Worker 만들기 (컴퓨터에서)

1. https://dash.cloudflare.com 에 가입하거나 로그인해요. 무료 플랜이면 충분해요.
2. 왼쪽 메뉴 **Storage & Databases → KV → Create a namespace**를 눌러요.
   - 이름: `hanbakwi` → **Add**
3. 왼쪽 메뉴 **Compute (Workers) → Workers & Pages → Create → Create Worker**를 눌러요.
   - 이름: `hangeol-widget` → **Deploy**
4. **Edit code**를 누르고 기존 코드를 모두 지워요. 이 폴더의 `worker.js` 내용을 통째로 붙여 넣고 **Deploy**를 눌러요.
5. Worker 화면 **Settings → Bindings → Add → KV namespace**를 눌러요.
   - Variable name: `HANBAKWI` (대문자 그대로)
   - KV namespace: 2번에서 만든 `hanbakwi` → **Save**
6. 이 Worker의 주소를 적어 둬요. 화면 위에 나오는 `https://hangeol-widget.○○○.workers.dev` 같은 주소예요.

## 2단계 · 보안키 만들고 서로 맞추기

1. 휴대폰 한바퀴 앱에서 **설정 → 아이폰 위젯 연동**으로 가요.
2. **보안키 생성**을 누르고 **보안키 보기**를 눌러 키를 복사해요. 영문과 숫자 64자예요.
3. 컴퓨터의 Cloudflare Worker 화면에서 **Settings → Variables and Secrets → Add**를 눌러요.
   - Type: **Secret**
   - Variable name: `SYNC_TOKEN`
   - Value: 2번에서 복사한 보안키 → **Deploy**
4. 다시 휴대폰 앱에서 아래처럼 입력해요.
   - **연결 주소:** 1단계 6번의 Worker 주소 (끝에 `/summary`는 붙이지 않아요)
   - **연결 보안키:** 방금 만든 키(이미 들어가 있어요)
5. **연결 저장 · 전송**을 눌러요. "위젯으로 누적시간을 전송했어요"가 나오면 성공이에요.
   - 이후로는 기록을 저장할 때마다 자동으로 다시 보내요.

## 3단계 · 아이폰 위젯 붙이기

1. App Store에서 **Scriptable**을 설치해요. 무료예요.
2. Scriptable을 열고 오른쪽 위 **＋**를 눌러 새 스크립트를 만들어요.
3. 이 폴더의 `hanbakwi-widget.js` 내용을 통째로 붙여 넣어요.
4. 맨 위 두 줄을 바꿔요.
   ```js
   const WORKER_URL = 'https://hangeol-widget.○○○.workers.dev';
   const SYNC_TOKEN = '2단계에서 만든 보안키';
   ```
5. 스크립트 이름을 `한바퀴`로 바꾸고, 아래 ▶ 버튼을 눌러 미리보기가 나오는지 확인해요.
6. 홈 화면 빈 곳을 길게 누름 → 왼쪽 위 **＋(편집)** → **Scriptable** → 크기(작게·중간·크게)를 고르고 **위젯 추가**를 눌러요.
7. 추가된 위젯을 길게 누름 → **위젯 편집** → **Script**를 `한바퀴`로 골라요.

## 위젯 모양

- **작게:** 겹친 링(최대 3개)과 오늘 한 시간 / 오늘 목표
- **중간:** 겹친 링, 항목별 이번 달 시간 / 월 목표, 오늘 한 시간
- **크게:** 중간 모양에 항목별 오늘 기록 목록이 더해져요
- 오늘 목표를 채우면 항목 색, 아직이면 빨강으로 보여요.
- 위젯은 약 15분마다 새로 고쳐져요. 아이폰 사정에 따라 더 늦을 수 있어요. 인터넷이 안 되면 마지막으로 받은 내용을 보여 줘요.

## 잘 안 될 때

| 증상 | 확인할 것 |
|---|---|
| 앱에서 "위젯 동기화 실패: 서버 오류 401" | 앱의 보안키와 Cloudflare의 `SYNC_TOKEN`이 한 글자도 다르지 않은지 확인해요. |
| "서버 오류 500" | Worker에 KV 연결(`HANBAKWI`)과 `SYNC_TOKEN`을 둘 다 넣었는지 확인해요. |
| 위젯에 "아직 받은 기록이 없어요" | 앱에서 **연결 저장 · 전송**을 한 번 눌러요. 위젯 스크립트의 주소와 보안키도 확인해요. |
| 위젯 숫자가 앱과 달라요 | 앱을 한 번 열어 기록을 저장하거나 다시 전송한 뒤, 위젯이 새로 고쳐질 때까지 기다려요. |

보안키는 비밀번호와 같아요. 다른 사람에게 보여 주거나 GitHub에 올리지 마세요.
이 폴더의 파일 두 개에는 실제 보안키를 적지 말고, Scriptable 안에서만 바꿔 넣어 주세요.
