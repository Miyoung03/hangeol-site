한결 · 밝은 모노라인 디자인 복원 버전
===================================

※ 이전 ZIP 원본 파일을 직접 수정한 결과가 아니라,
   이전 앱 화면과 확인 가능한 데이터 형식을 참고해 재구성한 복원본입니다.
※ 실행 전에 현재 앱의 '설정 → 내 기록 관리 → 전체 백업'에서 기록을 백업하세요.

디자인 변경
- 어두운 새 대시보드 대신 밝은 아이보리 배경과 흰색 카드 사용
- 항목별 누적시간을 슬라이드로 표시
- 항목마다 월 목표 설정, 시작/종료/직접 입력, 기록/통계/설정 유지
- 아이폰 홈 화면 기본 아이콘은 임시로 중립적인 한결 글자 아이콘 적용
- 별도로 제안한 새 홈 화면 아이콘은 선택 전까지 적용하지 않음

GitHub Pages 적용
1. 이 ZIP을 컴퓨터에서 압축 해제합니다.
2. GitHub의 기존 한결 저장소를 엽니다.
3. 같은 이름의 파일(index.html, app.js, sw.js, manifest.webmanifest,
   icon-180.png, icon-192.png, icon-512.png)을 업로드하여 교체합니다.
4. 약간 기다린 뒤 사이트를 새로고침합니다.
5. 홈 화면 아이콘은 아이폰의 캐시로 인해 바로 바뀌지 않을 수 있습니다.

중요한 점
- 같은 주소에서 사용하면 기존 한결 기록을 읽도록
  localStorage의 'hangeol-records-v1' 키를 사용합니다.
- Safari와 홈 화면 앱은 데이터 저장 공간이 달라질 수 있습니다.
- 홈 화면 앱을 삭제하거나 브라우저 데이터를 지우기 전에 반드시 백업하세요.
- 개인 앱 코드입니다. 서버에 기록을 전송하지 않습니다.

파일 내용
- index.html: UI 및 구조
- app.js: 타이머, 기록, 항목별 목표, 통계, 백업/복원
- manifest.webmanifest: 홈 화면 앱 설정
- sw.js: 오프라인 캐시
- icon-180/192/512.png: 임시 기본 홈 화면 아이콘
